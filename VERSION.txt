ThreadGens 0.7.0-p0-p1-p2-integrated

Branch: integration/p0-p1-p2-final

Integrated release:
- P0 content originality, semantic novelty, source-clean social rendering, five dynamic formats, timed visual states, and safe production routing
- P1 word/sentence captions, voice pools and delivery presets, concurrency-safe identity recency, and AI/manual provenance/disclosure metadata
- P2 final pre-publish repetition audit with exact/semantic/content/visual/identity/audio/format/pacing checks
- P2 consumes actual P1 per-segment voice sidecars and stable P1 provenance fields rather than relying on inferred launch-time state
- P1 identity history and P2 publish history both fail closed on malformed state
- P2 publish decisions use in-process plus OS-level transaction locking
- normal CLI, GUI compatibility path, legacy Runner, batch runner, Gradle application, and runnable JAR route through P2Entrypoint
- blocked output receives an audit report but is not recorded as approved publish history or promoted by the batch runner

Default histories:
- P0 generation history: data/generation_history.jsonl
- P1 identity history: data/identity_history.jsonl
- P2 approved publish history: data/publish_history.jsonl

Default outputs:
- generated script: output/script/generated_comments.txt
- screenshots: output/
- audio and P1 voice sidecars: output/audio/
- video clips/final video: output/video/
- P1 provenance: <output>/metadata/<prefix>-provenance.json and final.mp4.provenance.json
- P2 audit report: output/video/publish_audit.json

Release acceptance requires the exact integrated head to pass the combined Ubuntu and Windows smoke workflow.
