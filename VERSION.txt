ThreadGens 0.6.0-p1-content-variation

Branch: p1-content-variation-provenance-main

P0 content-originality release:
- production entrypoints route through P0Entrypoint
- CheckedRunner and the GUI inherit P0 behavior
- RawCheckedRunner is the explicit low-level compatibility/debug path
- five content-aware formats: thread_story, confession, debate, best_answers, escalating_conversation
- persistent deterministic novelty history with regeneration on rejected auto content
- local Ollama semantic novelty with nomic-embed-text for reworded story/joke/conflict detection
- malformed existing novelty history fails closed during automatic generation
- generated Reddit/X renderers omit fabricated engagement at source
- generated X output omits verification badges and precise fake timestamps
- narration is split into timed visual states targeting roughly 2.5-second content/focus changes
- each format has its own layout, motion behavior and final transition profile
- final delivery remains conventional H.264/AAC/yuv420p/+faststart
- stale segment/final MP4 files are removed before regeneration
- Windows setup pulls both llama3.1:8b and nomic-embed-text
- CI includes Java 21 compilation, P0 unit tests, real FFmpeg/ffprobe video tests for all five formats, and Windows PowerShell parser validation

P1 content-variation and provenance release:
- word-highlighted or sentence-timed ASS captions derived from exact narration and measured audio
- caption timing drives the completed P0 timed visual-state renderer
- configurable single, series-stable, and per-slide Kokoro/Piper voice selection
- natural, calm, energetic, and dramatic delivery presets with explicit speed/language/pause overrides
- persistent, concurrency-safe synthetic identity history across Reddit and X videos
- validated AI profile images are preferred for every slide when available
- JSON provenance manifests with SHA-256 artifact hashes and portable paths
- AI disclosure metadata embedded in segment and final MP4 files
- automatic generation always records AI content origin

Still included:
- optional OP-only image generation through local ComfyUI / RealVisXL
- local Kokoro and Piper TTS
- generated/imported profile images and usernames
- batch video creation and interactive Windows generation

Default output folders:
- generated script: output/script/generated_comments.txt
- screenshots: output/
- generated/imported profile cache: output/cache/pfp/
- OP image prompts/cache: output/cache/images/
- OP images: output/images/
- audio: output/audio/
- video clips and final video: output/video/
- novelty history: data/generation_history.jsonl (git-ignored)
- identity history: data/identity_history.jsonl (git-ignored)
- provenance manifests: output/metadata/
